# Changelog

本文件记录项目的重要版本级变化。更细的开发过程、验证命令和当前限制请查看 `docs/DEV_LOG.md`。

## Unreleased

### Added
- Added `docs/DEV_LOG.md` to track development purpose, changed files, validation commands, results, limitations, and next steps.
- Added `CHANGELOG.md` for high-level project change summaries.
- Added `scripts/check_depth_model_env.py` for checking transformers/PIL/torch depth-model environment.
- Added `scripts/depth_smoke_test.py` for generating real monocular depth maps from image/video inputs.

### Changed
- `RealDepthProvider` now uses a real `transformers.pipeline("depth-estimation")` backend instead of only being a placeholder.
- Real depth observation building now supports `--depth_model_name` and `--invert_depth`.
- Saved depth maps now include both `.npy` arrays and PNG visualizations.

### Removed
- Nothing.

## 2026-07-07 - Prototype Milestone

### Added
- Object-level scale-depth consistency residual `R_sd`.
- Ratio-space and log-space `R_sd` computation.
- Pairwise scale-depth residual matrix computation.
- Residual fusion module for object, pair, and clip-level scores.
- Synthetic observation experiments for validating scale-depth residual stability.
- Manual observation JSON pipeline.
- Video preprocessing pipeline for frame extraction and clip construction.
- Mock object/depth providers for reproducible pipeline testing.
- Real YOLO object detection provider based on ultralytics.
- YOLO environment check and smoke test scripts.
- Observation JSON read/write interfaces for frame, clip, and residual results.
- Multi-level residual visualization functions and demos.
- Scale prior resolver with exact category priors, aliases, and safe unknown-label handling.
- Depth provider interface, mock depth map generation, and bbox median depth extraction.

### Changed
- Real observation pipeline can now use YOLO detections instead of fixed mock objects.
- Scale prior lookup now supports coarse category aliasing instead of requiring every fine-grained class to have its own prior.
- Observation building can optionally replace default object depth with bbox-level median depth from a depth map.
- R_sd pipeline safely skips objects or pairs without usable scale priors instead of crashing.

### Current Limitations
- Real depth estimation is not yet connected; `RealDepthProvider` is currently a pluggable placeholder.
- Instance masks are not yet generated by a real segmentation model; bbox area is used as a temporary mask_area approximation.
- The current prototype validates the scale-depth component of the 3D structural constraint system, not a complete forged video detector.
- Optical flow, point tracking, occlusion ordering, and spatial correspondence residuals are still planned future modules.
